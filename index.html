ENGINEERING OVERVIEW

Zero-Trust Architecture

Every layer operates locally on Windows with zero cloud telemetry dependencies.

🛡️

PBKDF2 Salting & Key Derivation

All PINs are hashed using PBKDF2 with 100,000 iterations of SHA-256 and unique 16-byte cryptographic salts. Automatic upgrade from legacy single-pass SHA-256 upon verification.

📷

Stealth 5-Photo Burst

Upon breach detection, Aegis silently captures 5 consecutive forensic photos at 0.2s intervals to capture movement and facial angles before the intruder reacts.

🌐

Approximate IP Geolocation

Public network query estimates city and region coordinates. Clearly labeled as non-GPS network estimates to maintain complete evidentiary integrity.

🔒

Instant Host Lock (Win+L)

Direct integration with user32.dll LockWorkStation() secures the Windows session instantly before malicious tampering can occur.

📲

Offline GSM Hardware SMS

Sends emergency text alerts over local COM port GSM modems even if internet access is cut, with automatic fallback to offline disk queuing.

📧

Forensic Gmail SMTP Dispatch

Multi-part MIME email dispatcher with embedded snapshot attachments, location map links, and incident breakdown sent to the verified owner inbox.
